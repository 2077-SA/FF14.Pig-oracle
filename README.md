# 🐖 FF14 猪猪运势转盘 
一个基于《最终幻想14》玩家同人娱乐工具，整合了：
- 🎡 全玩法运势转盘（高难/狩猎/挖宝/钓鱼/生产/金碟/PVP/社交）
- 🎁 猪猪盲盒抽奖机（含 S怪今日可触发窗口）
- 🐗 S怪触发指南（7.0 / 6.0 / 5.0 / SS怪）及其模拟触发的爽感！
- 📋 狩猎运势综合建议
- 🏁 猪猪赛跑
- 🔮 猪猪塔罗牌
- 🥚 神鸟龙蛋计数器
- 🌾 5.0--6.0部分需要农场的统寄助手，帮助您更好了解自己的触发情况！
